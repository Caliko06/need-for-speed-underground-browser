How it works: a 2003 Windows game recompiled to WebAssembly

What runs in your tab is the game's own code from 2003. It was not rewritten and it is not emulated: the program was translated once, ahead of time, into something a browser can run.

Updated November 24, 2026

Static recompilation

The PC game is one Windows program, Speed.exe, made of machine code for 32-bit Intel processors. A tool reads that program and writes the same logic again as WebAssembly, the portable code format browsers run at close to native speed. This is called static recompilation: the translation happens before you ever open the page, not while you play.

An emulator would have to imitate a whole PC, instruction by instruction, every frame. Here the handling, the rival drivers, the menus and the career rules are the original ones, already in the browser's own format. The result is a file of about 70 MB that travels compressed in 11 MB.

A new home for an old program

The game still believes it is on Windows XP. It asks for windows, files, sound buffers, keyboard state and a DirectX 9 graphics card. A layer written for this project answers each of those calls with what a browser has:

  • Graphics: the DirectX 9 drawing calls are turned into WebGPU.
  • Sound: music and effects play through the browser's audio system.
  • Input: keys, gamepads and touch buttons are handed to the game as the keyboard codes it expects, which is why its own key table still applies.
  • Files: the game opens its data files as it always did, and the layer fetches only the parts it reads from the server.
  • Threads: the game runs off the page's main thread on shared memory, which is why the site is served with cross-origin isolation.
  • Saves: the save folder lives in memory and is copied to your browser's own storage a moment after each change.

The remaster layer

Because the page owns the drawing step, it can add things the 2003 renderer did not have: bloom on lights, edge smoothing, sharpening, anisotropic filtering, sharper car paint and optional high resolution textures. All of it is a layer on top. Switch the version to Original 2003 and the picture is the one the game always drew.

Try it
