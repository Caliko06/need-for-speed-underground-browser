How to enter cheat codes on PC and NFSU.cc

Follow these exact steps inside Need for Speed Underground (no text box appears on screen while you type):

  1. Open the Main Menu.
  2. Select Statistics.
  3. Press Delete (or Backspace) to return to the Main Menu and arm the code listener.
  4. Type any code from the table below in lowercase letters, then press Enter.

If accepted, the game unlocks the item for Quick Race and Customize immediately. Note that Speed.exe does not contain a money cheat or Level 3 performance cheat in its EasterEggs table; if you want every career car and upgrade open on NFSU.cc, choose Career > All open in the launcher.

Frequently asked questions

Why are some popular internet codes missing from this list?

Codes like regmebaby or opendoors belong to Need for Speed Underground 2 (2004), not Underground 1 (2003). The 33 codes above are the complete set actually compiled into Speed.exe.

Do these cheat codes work in the browser on NFSU.cc?

Yes. Because NFSU.cc runs a static WebAssembly recompilation of the original 2003 Speed.exe, the exact same EasterEggs handler listens for all 33 codes on the Main Menu after exiting Statistics.

Is there a cheat code for Level 3 upgrades or infinite cash?

No. The PC EasterEggs table only includes Level 1 and Level 2 performance parts (allmylvloneparts, allmylvl2parts) and Level 2 visual parts (seemylvl2parts). Level 3 upgrades and Junkman unique parts are earned in Go Underground career mode.
