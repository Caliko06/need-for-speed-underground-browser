Reading the binary: Ghidra, Hopper, REA and a census of names

Recompiling a game makes it run. Changing it, fixing it or adding options means understanding it, and a 2003 executable comes with no names, no symbols and no comments.

Updated November 21, 2026

The tools

  • Ghidra, run headless from scripts: the whole executable decompiled to C-like code, saved as text so any search tool can read it.
  • Hopper, a disassembler for macOS: a second decompiler with its own opinion of each function, exported the same way.
  • REA, a reverse engineering server that AI agents talk to over MCP (Model Context Protocol): open the binary, read a function's pseudocode, list who calls an address, read raw bytes.
  • objdump and Capstone for the plain instruction listing, the last word when the decompilers disagree.
  • The running game: a trace switch logs every Windows and DirectX call with its arguments, so what a function is believed to do can be checked against what it does.

Two tools or it does not count

Decompilers are wrong in small ways: a missed argument, a float read as an integer, a jump table cut short. So every value, file format or patch names what proves it (an address in the executable, a chunk id in a data file, a line in the code), read with REA plus a second tool. What is not proven is marked UNKNOWN, and nothing is built on it.

A census instead of a wiki

Names are plain tables, one per system: cars, camera, collision, menus, audio, the rival AI. Each row is an address, a name and a mark: V when it was read in the code, I when it is inferred, U when unknown. There are 56 of those tables with about 10,700 rows, next to a census of the 14,330 function entries in Speed.exe. A table can be searched, compared and checked by a script; a page of prose cannot.

An example

The phone controls have a BACK button. It does not fake a key and hope: the menu's action table in the game (address 0x7032d8) has an action Back, bound to Escape and Backspace. The touch button sends exactly that key, and the game does the rest the way it always did.

One note per system

What the game does inside is kept as one short note per system in docs/re/: how the camera follows the car, how rivals pick a line, how a track loads. They are maps, not essays, and they are on GitHub. AI agents do much of the reading under these rules: how that works.
