Runtime: MSVC CRT, SEH/EH and the engine base layer (Speed.exe PC)

Assets, Runtime & Shipping 108 verified Speed.exe addresses Speed.exe (2003, x86)
Updated 2026-11-25 View raw Markdown (.md) Source on GitHub

Marks: V = read in bytes/code and a second tool agrees (Hopper H, Ghidra G incl. its Function-ID library match "FID", capstone C), I = inferred, U = open. Names: census/names_runtime.tsv (126 rows: 90 V, 36 I). Same-address rows in other names_*.tsv were skipped.

Answer

  • The CRT is Visual Studio 2003 (7.1) release, static, in 0x670c6c..0x6849d0 (about 540 functions). It starts at __amsg_exit 0x670c6c

(PE entry 0x670cb5 = WinMainCRTStartup) and ends with __allshr/__allshl 0x6849a0/0x6849d0. Ghidra's FID names 232 of them as "Single Match".

  • Most of the "runtime" tag is not CRT. census/systems.tsv has 3,765 runtime functions: 1,228 of them are 6..10-byte SEH

unwind funclets at 0x684a00..0x6896e0 (Unwind@..., mov eax,FuncInfo; jmp ___CxxFrameHandler), 608 are real CRT, 29 are the engine base library, 235 are the online/network stack (0x660000..0x670bd0), and 641+619 are game code tagged by address band. Funclets are not callable functions; count them apart when you compute "named %".

  • The engine base layer is EA's b* library: allocator (bMalloc 0x565b60 over named pools, first one "Main Pool"), SlotPool

(fixed-size slots, 0x30-byte header), circular lists, string hash x33, 16-bit-angle trig, vector/matrix helpers, own printf (bPrintf).

  • Two float-to-int helpers exist: __ftol 0x672fc8 (changes the control word, 38 callers) and 0x674898 (341 callers; `fld st0; fst; fistp; fild;

fsub then rounds by the remainder, no control-word write). census/names_blur.tsv names 0x674898 _ftol; the bytes say it is the CW-free variant (__ftol2`-style). Not edited here (outside scope); the lifter treats both as float to int64.

Re-derived with a second tool (result)

Method: I read the bytes with capstone (tools/recomp/asm.py) and wrote down what the function does, then compared with Ghidra's FID name. Caveat: I had already seen Ghidra's name list for the CRT before reading the first 14 of these, so for them the independence is "the name was confirmed against the code", not a blind guess. The last 6 have no FID hit or a wrong one, so they are fully from code (H + G decompile + capstone).

Open
